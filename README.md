007 Character Collection — local demo

Extract this folder and open index.html in Microsoft Edge. Click the gold gun-barrel image to start. The opening zoom now uses one continuous image animation to reduce the visual jump. Your supplied gunshot plays at the end of the dive, the ding plays when the pack appears, and the second gunshot reveals three face-down cards. Click each card to flip it.

The ZIP download is built locally from embedded card images, so it does not require an internet connection or fetch local files.
